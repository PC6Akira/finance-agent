# memory — 项目记忆

本目录沉淀**本项目的关键决策与交涉成果**，随 git 仓库一起迁移。
任何新 agent 会话（上下文不足时）读这里即可快速恢复工作上下文。

## 文件索引

| 文件 | 内容 |
|------|------|
| [positioning.md](positioning.md) | 项目定位、红线（做什么 / 不做什么） |
| [tech-stack.md](tech-stack.md) | 技术栈、存储方案、数据源 |
| [decisions.md](decisions.md) | 决策日志、已确认项、待审核清单 |
| [../TASKS.md](../TASKS.md) | 功能实现清单（逐条测试通过） |

## 使用约定

- 每确认一个决策，就在 `decisions.md` 追加一条并注明日期。
- 红线（"不做什么"）只增不减，任何改动需用户明确批准。
- 本目录与代码一起 commit，保证可迁移。
