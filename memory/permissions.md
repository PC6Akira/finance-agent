# 权限模型（Permissions）

> 金融 agent 运行时行为许可，三档：🟢 允许（自动）· 🟡 需用户许可（每次确认）· 🔴 禁止（硬红线，永不）。
> 本文件是权威来源，改档需用户明确批准（见红线 #5）。

## 执行机制

- **软约束**：本清单注入系统提示词 `prompts/system.md`，agent 自觉遵守。
- **硬约束**：🟡 类操作在对应工具函数内加 guard，未获用户许可直接返回拒绝。
- **触发暂停**：🟡 类操作通过 goal loop「需人决策则暂停」分支询问用户。

---

## 🔴 红线（禁止，永不执行）

1. 给投资建议 / 买卖决策 / 预测涨跌
2. 任何交易下单（现在无接口，未来也禁止）
3. 修改 `.env` / 密钥文件
4. 删除用户已确认的数据库数据（不可逆删除）
5. 修改红线规则本身（`positioning.md` 的"不做什么"）
6. git 破坏性操作（`reset --hard`、force push、删提交）

## 🟡 需用户许可（每次操作前确认）

7. 数据库增 / 删 / 改
8. 删除 / 覆盖现有文件
9. git commit / push
10. 修改决策记录 `memory/decisions.md`
11. 修改 `TASKS.md` 验收状态（打勾"已通过"）
12. 把**用户个人持仓/资产数据**外发给 LLM 或第三方
    - 注：公开的基金季报持仓不属于此列，可自动处理；仅用户**个人**持仓需确认。
13. 安装新的第三方依赖
14. 消耗付费或配额资源（未来若有付费 API）

## 🟢 允许（自动，无需逐次确认）

15. 读取项目文件、查询数据库（只读）
16. 拉取公开市场数据（akshare 净值/持仓/季报、Bocha 搜索）
17. 写日志、缓存、临时文件
18. 在项目内新建代码/工具文件
19. 读取 `.env` 使用 key（但不把 key 内容打印出来）
